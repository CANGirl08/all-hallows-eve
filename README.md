# All Hallows Eve Countdown

A 31-door October advent calendar of Halloween history and folklore by CAN Girl
([captureadventurenow.com](https://www.captureadventurenow.com/post/all-hallows-eve-countdown)).

- `index.html` is the whole app: stories, Myth or Truth, the passport and world map, and the Instagram cards.
- `img/` holds the story photos (`dayNN.jpg`) and the link-preview image (`share.jpg`).
- A new door unlocks each night in October (by the visitor's own date). Outside October all doors are open.
  Add `#preview` to the address to see every door at any time.
